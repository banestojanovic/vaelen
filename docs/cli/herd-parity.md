# Herd CLI parity matrix

Scope: every command documented in Herd's macOS [Command Line](https://herd.laravel.com/docs/macos/advanced-usage/herd-cli) page, grouped exactly as Herd presents it. This is a living acceptance ledger, not a claim that help text implies working behavior. **Current implementation** describes the checkout/app before the next installed update; runtime acceptance is recorded separately. Herd reference checked 2026-09-25.

## Reading this matrix

- `working` = an implemented Vaelen operation backed by Core, a native macOS integration, or a real child process; parse/help alone is not working behavior.
- `partial` = useful behavior exists but does not yet preserve all of Herd's semantics or requested acceptance.
- `missing` = no supported implementation. Do not add the command to `val list` until its underlying behavior exists.
- UI column is a counterpart, not proof of parity. Menu-bar and Settings state must continue to reflect Core.
- Side effects call out persistent/system changes. Acceptance tests must use temporary fixtures or isolated service instances before touching real project state.
