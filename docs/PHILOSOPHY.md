* macOS first, macOS only.
* Native processes over containers
* No Docker or VM dependency
* Install only what you use.
* Off means off.
* Uninstalled means absent.
* Every module owns its lifecycle.
* Every resource cost is visible.
* Local-first. No account required.
* Core stays small.
* Modules compose instead of coupling.
* CLI and GUI control the same underlying system.
* Vaelen orchestrates great existing tools rather than unnecessarily reinventing them.
* A project should be reproducible with `val up`
* It should feel like Apple built developer tooling for the Mac.
* No unnecessary external dependencies in Vaelen Core. Modules may integrate mature upstream software, but those dependencies must remain isolated, observable and removable.
