# Grounding for Laravel connection acceptance

The existing package-backed acceptance lives in `Scripts/tests/val-project-database-provisioning-test.sh` and `Tests/VaelenIPCTests/ProjectDatabaseProvisioningEndToEndTests.swift`. The shell recipe builds `val`, verifies the installed Vaelen MySQL 8.4.11 and PHP 8.4.27 package metadata, then runs one selected XCTest. The XCTest owns a unique `/private/tmp/vaelen-dbprov-<UUID>` root, private Core, disposable MySQL data, linked project, `.env`, and cleanup. It provisions through actual `val`, reviews and applies the database connection, then parses the output and authenticates PDO. The test writes a minimal PHP `artisan` marker at project setup; it currently does not boot Laravel.

The existing `.env` fixture begins with a comment containing invalid UTF-8 byte `0xff`. Real `phpdotenv` cannot load that file, so the Laravel acceptance must use a valid UTF-8 starting `.env` for this fixture while existing Core tests retain malformed-byte and preservation coverage. The acceptance must verify the actual bytes written by `val`, not reimplement its transformation.

The installed Vaelen PHP 8.4.27 package is available under `~/Library/Application Support/Vaelen/packages/php/8.4.27/php`. System Composer is 2.9.8 and uses Homebrew PHP 8.5.6 by default. Any Composer resolution must run under the installed Vaelen PHP 8.4.27 binary so dependencies match the runtime under test. Current Laravel 13 deployment documentation says the framework skips loading `.env` when cached config exists, and config values must have been captured through config files before caching. The test should assert selected `database.default` and `database.connections.mysql.{host,port,database,username,password}` values by comparing them to a private expected-value file, with failures naming only the field.

Evidence: the verified previous live run at `/private/tmp/vaelen-project-database-evidence.hds0kU`, current test/script sources above, and official Laravel deployment docs at https://laravel.com/docs/13.x/deployment.
